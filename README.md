# Hellgate Manor — Final Release

Release build based on the v1.9.5 performance-optimised game.

- 50-wave normal campaign with the long-form late-game wave counts intact.
- New Game+ / Hell Mode remains available after completion.
- Wave 40 visual transformation, Wave 50 dedicated music, final dawn sequence, Overcharge, Soul Extraction and all defence systems are unchanged from the tested performance build.
- Enemy pools, texture prewarming, effect optimisations and reduced runtime allocations from v1.9.5 are retained.
- Developer/test controls and diagnostics are removed from this release build.

Required game assets, fonts and sounds should remain in their existing repository folders.
