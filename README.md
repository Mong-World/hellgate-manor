# Hellgate Manor — Procedural Visual Pass v0.6

This build is a more ambitious **procedural art pass** for testing directly in Portals.

## Focus of v0.6

- Rebuilt Gothic manor with more layered architecture and silhouette detail
- Rebuilt Husk with a more monstrous, elongated shape
- Larger clear battlefield in the middle
- Forest pushed firmly to the far left
- Stronger moonlight, warmer manor glow, more atmosphere
- Better 2.5D dragging and downward ground slams
- Impact ring, ash burst and soul ember effects preserved

## Files to replace in your repository

You can replace:

- `index.html`
- `style.css`
- `package.json`
- `README.md`
- `src/`

You do **not** need to change your existing GitHub Actions workflow if it is already working.

## Important folders that must exist

- `src/effects/AshExplosion.js`
- `src/effects/ImpactRing.js`
- `src/effects/SoulEmber.js`

## Build

Portals should still point to the built `portals-build` branch generated by your workflow.
